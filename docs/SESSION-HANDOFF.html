01

What this is

A journey-first knowledge platform for the UAE property ecosystem — not a listing portal, not a developer brochure, not a SaaS marketing site. It explains how property moves from land to living, helps a visitor find where they fit, then reveals the ecosystem behind it, and only then introduces the product.

The audience is global. Most readers have no prior UAE knowledge, so local terms are explained at first use rather than assumed. The site is currently education-first: the demo CTA appears only on /platform.

02

Rules that must not be broken

Each of these was a real defect that got fixed. Three are now guarded by tests — if you break them, the suite fails.

One canonical lifecycle test-guarded

app/data/journey.ts holds twelve stages. The hero ribbon, persona flows and the 24 detailed stages in reos.ts are all projections of it. The site once shipped four competing stage lists. Do not add a fifth.

Order is not sequence test-guarded

Stages carry runsWith. In UAE off-plan development, marketing and sales run during construction — escrow exists precisely because buyers pay while the building goes up. Flattening this into a queue teaches a process that does not exist. A test asserts the construction stage says so.

Demo CTA lives only on /platform test-guarded

The site is educational. A sales CTA in the page furniture undercuts that. A test asserts it appears on no other page.

Authorities are a rail, not a cluster

Group 03 is rendered as a separate rail beneath the four clusters because authorities issue the approvals that gate everyone else — compulsory and external, where every other participant is appointed and commercial.

Honest status labels

Validated / To Be Validated / Illustrative / Future REOS Capability. Do not remove these to make the product look more finished — they are a credibility and legal-exposure decision, and the same discipline covers the Arabic review notice.

Jurisdiction discipline

Requirements differ per emirate and per zone. Dubai guidance is never presented as UAE guidance. Every stage carries a jurisdiction note.

05

Verifying work

Screenshots via the in-app browser pane are unreliable on this site — captures ignore scroll and sometimes return blank frames. Use Playwright driving the installed Chrome; playwright-core is already a dev dependency and needs no browser download.

npm run lint && npx tsc --noEmit
npm run build          # 169 static pages
npm run build:sites    # worker output — tests read from dist/
node --test tests/rendered-html.test.mjs   # 10 tests

# tests read dist/, so ALWAYS build:sites first or you test stale output

Watch for: the tests run against dist/server/index.js. Skipping build:sites means asserting against the previous build — that happened once and produced a false pass.

08

If you only read one thing

This project's recurring failure mode is two models of the same thing drifting apart. It has happened three times: a consumer funnel versus a development model; four competing lifecycles; a homepage route list versus the /roles route list.

Each time, the fix was to collapse to one source and make everything else a projection of it. Before adding any list, stage, route or persona, check whether it already exists somewhere — and if it does, project from it rather than restating it.
