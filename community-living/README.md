# Community Living UAE — REMEDIATION-001

Isolated prototype implementing the Phase 1–12 website remediation program plus production gates §§25–40.

## Purpose
Resident-first UAE community-living knowledge and navigation layer. This is intentionally separated from the main REOS application until validation and approval.

## Flagship concepts
- Ask My Community™ — pre-authored demonstration only until a verified knowledge backend exists.
- Community Passport™ — structured community profile with source, last-verified and status fields.

## Safety
No fabricated regulatory advice, partnerships, testimonials, market metrics, complaint volumes or community contractual responsibilities. Unknown community data is labelled `Information being verified`.

## QA gates
- Resident-first 2-second proposition
- Product utility above the fold
- Responsive mobile-first behavior
- Keyboard/focus/reduced-motion support
- Evidence/provenance presentation
- Consumer vs enterprise vs investor separation
- Structured metadata
- No production promotion without preview validation

## Deployment
The prototype is deployed independently to Vercel. Do not merge this branch into `main` until visual/browser QA and stakeholder approval are complete.
